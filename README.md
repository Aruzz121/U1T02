# U1T02

PROBLEMA 3.1 - Convolucion 2D con padding (C# / .NET 10, solo Windows)

1. Instala el .NET 10 SDK (https://dotnet.microsoft.com/download).
2. Pon tus imagenes (.png .jpg .jpeg .bmp) en Problema_3.1_CSharp\entrada
3. Doble clic en Problema_3.1_CSharp\ejecutar.bat
4. Los resultados salen en Problema_3.1_CSharp\salida (se abre solo).

Abre explicacion_interactiva.html para ver paso a paso como funciona.
Al correr el programa, en salida se crea <imagen>_reconstruccion.html: abrelo y pulsa Run para ver como se reconstruye TU imagen de entrada.
reconstruccion_interactiva.html (en esta carpeta) tiene un selector para elegir cualquier imagen sin correr el programa.
